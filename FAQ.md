# FAQ — DolphinAnty Desktop

## Общие вопросы

### Что такое DolphinAnty Desktop?
Десктопный антидетект-браузер для мультиаккаунтинга под Windows 10 (x64). Позволяет создавать изолированные браузерные профили с уникальными цифровыми отпечатками (fingerprint), управлять прокси, автоматизировать действия через сценарии, собирать cookies и синхронизировать действия между профилями.

### Какие системные требования?
- **ОС:** Windows 10 x64
- **Node.js:** 18 или выше
- **npm:** 9 или выше
- **Браузер:** Google Chrome или Chromium, установленный в системе
- **RAM:** минимум 4 ГБ (рекомендуется 8+ ГБ для работы с 10+ профилями одновременно)
- **Диск:** ~500 МБ для приложения + ~50 МБ на каждый профиль

### Сколько профилей можно создать?
Ограничений на количество профилей нет. Протестировано создание 120+ профилей. Одновременный запуск зависит от ресурсов ПК — каждый работающий профиль потребляет ~200–400 МБ RAM.

## Установка и запуск

### Как установить?
```bash
cd DolphinAntyDesktop
npm install
npm run build
npm start
```

### При `npm install` ошибка с native-модулями
Проект использует `sql.js` (чистый JavaScript), который не требует компиляции. Если видите ошибки — убедитесь, что у вас Node.js версии 18+:
```bash
node --version
```

### Приложение не запускается / белый экран
1. Убедитесь, что сборка прошла успешно: `npm run build`
2. Проверьте, что папка `dist/` содержит файлы `main/main.js` и `renderer/bundle.js`
3. Запустите с DevTools для диагностики: `npm start -- --dev`
4. Проверьте консоль DevTools (вкладка Console) на наличие ошибок

### В логе ошибки `Autofill.enable` и `language-mismatch`
Это стандартные предупреждения DevTools от Electron. Они **не влияют** на работу приложения и могут быть проигнорированы.

## Профили

### Как создать профиль?
1. Перейдите в раздел **Профили**
2. Нажмите **"Создать профиль"**
3. Введите имя, при необходимости — группу, теги, заметки
4. Для массового создания укажите число в поле "Кол-во профилей"
5. Нажмите **"Создать"**

### Как запустить профиль?
Нажмите кнопку **"Запустить"** напротив нужного профиля в таблице. Откроется отдельное окно браузера с подменённым fingerprint.

### Браузер не запускается / ошибка при запуске профиля
1. Перейдите в **Настройки**
2. В поле **"Путь к Chromium"** укажите полный путь к `chrome.exe`, например:
   ```
   C:\Program Files\Google\Chrome\Application\chrome.exe
   ```
3. Сохраните настройки и попробуйте снова

### Как проверить, что fingerprint подменён?
Запустите профиль и в открывшемся браузере перейдите на:
- https://browserleaks.com/canvas — проверка Canvas fingerprint
- https://browserleaks.com/webgl — проверка WebGL (vendor/renderer)
- https://browserleaks.com/javascript — проверка User-Agent, platform, языка
- https://pixelscan.net/ — комплексная проверка
- https://whoer.net/ — проверка IP и DNS (при использовании прокси)

### Как экспортировать/импортировать профили?
- **Экспорт:** выделите профили чекбоксами → нажмите "Экспорт" в bulk-панели
- **Импорт:** используйте кнопку "Импорт" и загрузите JSON-файл с профилями

### Что происходит с cookies при закрытии профиля?
Cookies автоматически сохраняются при остановке профиля через кнопку "Остановить". Если браузер закрыт вручную (крестик), cookies из текущей сессии могут не сохраниться.

## Прокси

### Какие типы прокси поддерживаются?
- HTTP
- HTTPS
- SOCKS4
- SOCKS5

### Как добавить прокси?
**Вручную:**
1. Раздел **Прокси** → **"Добавить прокси"**
2. Заполните хост, порт, тип, логин/пароль

**Списком:**
1. Нажмите **"Импорт списком"**
2. Вставьте прокси в формате (по одному на строку):
   ```
   ip:port
   ip:port:login:password
   ```
3. Выберите тип и нажмите "Импортировать"

### Как проверить работоспособность прокси?
- Кнопка **"Проверить"** напротив конкретного прокси
- Кнопка **"Проверить все"** для массовой проверки
- Статус отобразится: Активен (зелёный), Мёртв (красный), Не проверен (жёлтый)

### Как привязать прокси к профилю?
При создании или редактировании профиля выберите прокси из списка. Также можно массово назначить прокси через bulk-действие "Установить прокси".

## Сценарии (автоматизация)

### Как создать сценарий?
1. Раздел **Сценарии** → **"Создать"**
2. Введите имя и описание
3. Добавляйте шаги кнопкой **"Добавить шаг"**
4. Сохраните сценарий

### Какие типы шагов доступны?
| Тип | Описание | Параметры |
|-----|----------|-----------|
| navigate | Переход по URL | url |
| click | Клик по элементу | CSS-селектор |
| type | Ввод текста | CSS-селектор, текст |
| wait | Пауза | миллисекунды |
| waitForSelector | Ожидание элемента | CSS-селектор |
| scroll | Прокрутка | расстояние в пикселях |
| screenshot | Скриншот | путь к файлу |
| evaluate | Выполнить JS | JavaScript-код |
| keypress | Нажатие клавиши | название клавиши |
| select | Выбор в dropdown | CSS-селектор, значения |
| hover | Наведение курсора | CSS-селектор |
| cookie_set | Установить cookies | массив cookies |
| cookie_clear | Очистить cookies | — |
| loop | Цикл | кол-во итераций, вложенные шаги |

### Как запустить сценарий на нескольких профилях?
1. Сначала **запустите** нужные профили (они должны быть в статусе "Запущен")
2. В сценарии нажмите **"Запустить"**
3. Выберите профили из списка запущенных
4. Сценарий выполнится на каждом выбранном профиле

### Что делать, если шаг сценария падает с ошибкой?
При добавлении шага можно выбрать поведение при ошибке:
- **stop** — остановить сценарий
- **skip** — пропустить шаг и продолжить
- **retry** — повторить шаг (укажите количество попыток)

## Cookie Robot

### Что делает Cookie Robot?
Автоматически посещает указанные URL-ы в выбранных профилях, прокручивает страницы, кликает по случайным ссылкам — имитирует реальную активность для "прогрева" профилей и накопления cookies.

### Как настроить Cookie Robot?
1. Раздел **Cookie Robot**
2. Укажите имя, список URL (по одному на строку)
3. Выберите профили (должны быть запущены)
4. Настройте параметры: визиты на URL, задержки, прокрутку, клики по ссылкам
5. Нажмите **"Запустить"**

### Можно ли остановить Cookie Robot в процессе?
Да, нажмите кнопку **"Остановить"**. Прогресс будет отображаться в реальном времени.

## Синхронизатор

### Как работает синхронизатор?
Один профиль назначается **мастером**, остальные — **подчинёнными**. Все действия в мастер-профиле (клики, ввод текста, навигация, прокрутка) автоматически дублируются в подчинённые профили с небольшой задержкой.

### Как запустить синхронизацию?
1. Запустите минимум 2 профиля
2. Раздел **Синхронизатор**
3. Выберите мастер-профиль из выпадающего списка
4. Отметьте подчинённые профили
5. Настройте, что синхронизировать (мышь, клавиатура, навигация, прокрутка)
6. Нажмите **"Запустить синхронизацию"**

## REST API

### Как включить API?
1. Раздел **Настройки**
2. Включите **"API сервер"**
3. Укажите порт (по умолчанию 3001)
4. Сохраните и **перезапустите** приложение

### Примеры запросов
```bash
# Статус приложения
curl http://127.0.0.1:3001/api/v1/status

# Список профилей
curl http://127.0.0.1:3001/api/v1/profiles

# Создать профиль
curl -X POST http://127.0.0.1:3001/api/v1/profiles \
  -H "Content-Type: application/json" \
  -d "{\"name\": \"New Profile\", \"tags\": [\"api\"]}"

# Запустить профиль
curl -X POST http://127.0.0.1:3001/api/v1/profiles/{id}/start

# Остановить профиль
curl -X POST http://127.0.0.1:3001/api/v1/profiles/{id}/stop

# Список прокси
curl http://127.0.0.1:3001/api/v1/proxies

# Добавить прокси
curl -X POST http://127.0.0.1:3001/api/v1/proxies \
  -H "Content-Type: application/json" \
  -d "{\"host\": \"1.2.3.4\", \"port\": 8080, \"type\": \"http\"}"

# Массовое действие
curl -X POST http://127.0.0.1:3001/api/v1/bulk \
  -H "Content-Type: application/json" \
  -d "{\"type\": \"launch\", \"profileIds\": [\"id1\", \"id2\"]}"
```

### Формат ответа API
Все ответы имеют единый формат:
```json
{
  "success": true,
  "data": { ... }
}
```
При ошибке:
```json
{
  "success": false,
  "error": "Описание ошибки"
}
```

## Безопасность

### Как шифруются данные?
Данные профилей шифруются алгоритмом **AES-256-CBC** с уникальным IV (вектором инициализации) для каждой записи. Ключ шифрования можно задать через переменную окружения `DOLPHIN_ENCRYPTION_KEY`.

### Можно ли отключить шифрование?
Да, в разделе **Настройки** снимите галочку **"Шифрование данных"**. Это ускорит запись/чтение, но данные будут храниться в открытом виде.

### Где хранятся данные?
- **База данных:** `%APPDATA%/dolphin-anty-desktop/dolphin_anty.db`
- **Профили браузера:** `%APPDATA%/dolphin-anty-desktop/browser_profiles/{id}/`

## Сборка и распространение

### Как собрать .exe установщик?
```bash
npm run package
```
Установщик появится в папке `build/`. Формат — NSIS (стандартный Windows-установщик).

### Как запустить тесты?
```bash
npm test
```
Запустит 80 тестов (fingerprint, профили, прокси, сценарии, шифрование).

## Решение проблем

| Проблема | Решение |
|----------|---------|
| Белый экран | Пересоберите: `npm run build`, затем `npm start` |
| Браузер не запускается | Укажите путь к Chrome в Настройки → Путь к Chromium |
| Ошибка `ENOENT chrome.exe` | Chrome не найден. Установите Chrome или укажите путь вручную |
| Тесты не проходят | `npm install`, затем `npm test` |
| Порт API занят | Измените порт в Настройки → Порт API |
| Высокое потребление RAM | Уменьшите число одновременно запущенных профилей в настройках |
| Прокси не работает | Проверьте формат: `ip:port:login:password`. Нажмите "Проверить" |
| Fingerprint не подменяется | Убедитесь, что профиль запущен через приложение, а не напрямую через Chrome |
