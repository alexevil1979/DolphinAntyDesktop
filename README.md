# DolphinAntyDesktop

Десктопный аналог Dolphin Anty для Win10.

## Возможности

- Управление браузерными профилями с уникальными отпечатками
- Прокси-менеджмент
- Автоматизация через сценарии (Puppeteer)
- Шифрование данных профилей

## Запуск

```bash
npm install
npm start
```

## Сборка

```bash
npm run package
```

## Тесты

```bash
npm test
```
